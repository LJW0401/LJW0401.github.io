Agent Hive

终端智能体并行管理 — 基于 Web 的多终端管理器，支持并行运行 AI Agent 或其他终端任务。

功能特性

  • 多终端并行 — 每个项目支持最多 5 个终端标签页，默认终端（Agent）始终保持连接
  • 项目容器 — 每个容器包含独立终端组 + 待办清单，可编辑名称
  • 双布局模式 — 桌面端支持多项目（2×2 网格）和单项目（全屏）两种布局，一键切换，状态持久化
  • 可调布局 — 桌面端/移动端均可拖拽分割线调整待办/终端比例
  • 终端懒加载 — 默认终端（Agent）始终保持连接，额外终端仅在激活时加载，切换离开后释放
  • 完整终端模拟 — 支持 ANSI 颜色、vim、htop 等 TUI 程序（基于 xterm.js）
  • 移动端适配 — 滑动切换项目、7/3 默认布局（终端在上）、…
