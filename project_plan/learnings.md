## 2026-08-25

### Bug 修复：文档侧边栏视图与筛选链接无效
- **发现于**：用户报告
- **现象**：在静态文档页点击目录、标签、归档或具体标签后，URL 查询参数变化，但页面仍显示全部文档。
- **根因**：源站依赖服务端读取 `view` / `tag` / `year` 查询参数并渲染不同 HTML，导出到 GitHub Pages 时只保留了默认列表 HTML，且没有对应的客户端渲染逻辑。
- **修复**：新增静态站客户端视图解析与渲染，复刻源站的目录树、标签卡片、年/月归档折叠和文档筛选，并同步侧边栏选中态。
- **回归测试**：`tests/docs-sidebar.test.mjs` 中的查询参数视图切换、分组层级和页面模块接入用例。
- **为什么原测试没覆盖**：仓库原先没有测试框架或静态导出后的查询参数导航用例，导出验收只检查了页面和链接存在，未检查点击后的可观测内容变化。
- **紧急程度**：中
- **衍生改进建议**：后续每次从服务端导出静态站时，都应把依赖查询参数的页面纳入真实浏览器冒烟测试。
